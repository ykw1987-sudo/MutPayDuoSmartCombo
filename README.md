麥畀多：至平組合


同樣咁食，唔好畀多咗。

「麥畀多：至平組合」是一個獨立的 iOS 餐點價格比較及計算工具，協助用戶在落單前比較套餐、散叫、不同數量及晚上 6 時後可用的分享盒配搭。

本 App 的重點不是叫你食少啲，而是幫你先睇清楚不同配搭的價格，避免因為揀錯組合而為同一餐無端端畀多錢。

主要功能

套餐及散叫比較

選擇你想食的餐點後，可以分別記錄套餐及散叫數量，清楚比較不同食法的價格。

智能搵出至抵組合

本 App 會按照你選擇的餐點、數量及價格，重新比較不同套餐分配，協助你找出更合理的組合。內容完全相同的方案不會重複顯示，主推薦方案會優先保留。

晚上 6 時後分享盒

晚上 6 時後可用的分享盒會加入餐點比較，讓你在晚市時段也可以檢查不同配搭，避免錯過較合理的組合。

自訂本機價格

如果你見到的價格與預設資料不同，可以修改單點及套餐價格。自訂價格只儲存在你的裝置內，用於本機計算，不會主動上傳。

清楚顯示價格差異

結果頁會顯示原本選擇、智能方案及價格差異，讓你在落單前知道自己是否可能因配搭不同而買貴。

使用方法

首先在主畫面選擇餐點分類，再按每項餐點的「套餐」或「散叫」按鈕，設定想要的數量。完成選擇後，按下計算按鈕，App 會顯示原本選擇及可比較的方案。

如需配合實際分店價格，可以長按餐點修改價格。完成後再次計算，結果會按照你輸入的本機價格更新。
